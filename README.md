# Лог обучения

Статическое Vanilla JS SPA для личной системы обучения.

## Запуск

Проект не использует сборщик и внешние зависимости. Откройте его через любой локальный HTTP-сервер, чтобы браузер корректно загрузил ES-модули.

Например, из корня проекта:

```powershell
py -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Содержание

- `Лаборатория` хранит сырые мысли и гипотезы.
- `Mental Models` хранит кристаллизованные принципы.
- `Блог` хранит личную рефлексию.
- `Объяснения` фиксируют темы, объяснённые своими словами.

Все записи находятся в `src/shared/data/mock-db.js` и изменяются вручную.
